# Сайт для студии мебели «Caramel» (`vk.ru/caramelmebel`)

Полноформатный продающий сайт в фирменной эстетике **Warm Obsidian & Caramel Architectural Atelier**, собранный на **100% реальных фотографиях, кейсах, отзывах и реквизитах** студии мебели на заказ «Карамель» (г. Подольск, юг Москвы и МО).

## Ключевые особенности проекта
- **Живое портфолио (24 реальных объекта):** фильтрация по родным категориям студии (`Кухни`, `Распашные шкафы`, `Шкафы-купе`, `Гардеробные`, `Спальни, санузлы и детские`), лайтбокс с переключением ракурсов, разбором фасадов/фурнитуры и прямой ссылкой на оригинальный пост ВКонтакте.
- **Личный бренд основателя:** раздел с реальными портретами **Владислава Алёхина** и историей из его закреплённого поста (`wall-217330319_96`).
- **Честная анкета «Расчёт стоимости за 1 день» (без фейкового калькулятора):** построена один в один по опроснику студии в ВК — выбор вида мебели, срока покупки, комфортной вилки бюджета (`100–130 т.р.` … `более 400 т.р.`), опции пересчёта готового эскиза и способа связи (**Telegram / Max / По телефону**).
- **Юридическая чистота (152-ФЗ) и безопасность заявок:** страница [privacy.html](privacy.html) с проверенными реквизитами ИП Алёхина В. С. (`ИНН 503620111969`), ссылка на официальные документы студии на Яндекс.Диске, серверные обработчики [netlify/functions/lead.js](netlify/functions/lead.js) и [api/lead.php](api/lead.php) без утечки токена бота в браузер.
